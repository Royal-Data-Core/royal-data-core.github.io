## Project Orientation Handoff Document

### 1. Color Palette

| Name       | HEX      | Usage          |
|------------|----------|----------------|
| Primary    | #007BFF  | CTAs, headers  |
| Secondary  | #6C757D  | Subtle text    |
| Success    | #28A745  | Success states |
| Danger     | #DC3545  | Error states   |

### 2. Typography

**Font Family:** 'Inter', sans-serif

| Component       | Size   | Weight | Line Height |
|-----------------|--------|--------|-------------|
| Headers (H1)    | 2.5rem | 700    | 1.2         |
| Body Text       | 1rem   | 400    | 1.6         |
| Buttons         | 1rem   | 600    | 1.5         |

### 3. Layout

**Grid System:** 12-column responsive grid

**Spacing Scale (in px):**
- 4
- 8
- 12
- 16
- 24
- 32

**Margins:**
- Container: 24px
- Sections: 32px

**Alignment:**
- Text: Left-aligned
- Images: Center-aligned

### 4. Critical Specifications

- All components must use the specified color palette
- Typography must be applied consistently across all UI elements
- Layout must follow the grid system for responsive design
- Accessibility: WCAG 2.1 AA compliance required
