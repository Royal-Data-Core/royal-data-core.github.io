# Required Environment Variables

## Secrets
- `GITHUB_TOKEN` (required for deployment)
- `FORMSPIREE_ID` (if using Formspree)
- `GOATCOUNTER_URL` (if using GoatCounter)

## Public Variables
- `PUBLIC_SITE_URL` (required)
- `PUBLIC_FORMSPREE_ID` (if using Formspree)
- `PUBLIC_GOATCOUNTER_URL` (if using GoatCounter)
